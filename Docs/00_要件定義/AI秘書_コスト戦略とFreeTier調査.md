# AI秘書エージェント コスト戦略とFree Tier調査報告

## 1. 概要
本ドキュメントでは、AI秘書機能（特にVer3以降のDeep Memory機能）を持続可能かつ低コストで運用するための戦略として、Google Gemini API の **Free Tier (無料枠)** 活用と **BYOK (Bring Your Own Key)** モデルについてまとめる。

---

## 2. Gemini API Free Tier の仕様 (2025年時点)

Google AI Studio経由で発行されるAPIキーには、非商用・検証・個人利用向けに強力な無料枠が設定されている。

### 主な制限事項 (Limits)
*   **RPM (Requests Per Minute)**: **15 RPM** (1分間に15回まで)
*   **RPD (Requests Per Day)**: **1,500 RPD** (1日1,500回まで)
*   **TPM (Tokens Per Minute)**: **100万 TPM** (1分間に100万トークンまで)
*   **入力ファイル数**: 画像・動画なども含め十分な余裕あり

### 評価
*   **秘書アプリとしての適性**: 
    *   1分間に15回も「AIブリーフィング」を生成することは現実的にないため、**個人の秘書用途としては実質無制限**に近い。
    *   1日1,500回の上限も、5分に1回ログを送っても到達しないレベルであり、余裕がある。

---

## 3. 推奨ビジネスモデル: BYOK (Bring Your Own Key)

開発者が全ユーザーのAPIコストを負担する従来のSaaSモデルではなく、ユーザー自身がAPIキーを取得して設定する **BYOKモデル** を採用する。

### 仕組み
1.  ユーザーは [Google AI Studio](https://aistudio.google.com/) で個人のGoogleアカウントを使ってAPIキーを取得する（無料）。
2.  「AI秘書エージェント」のインストール時または設定画面で、そのAPIキーを入力する。
3.  アプリはユーザーのAPIキーを使用してGeminiを呼び出す。

### メリット
*   **運用コスト 0円**: ユーザー数が100万人になっても、サーバーサイドでのAPI課金が発生しない。
*   **スケーラビリティ**: 制限（RPM/RPD）は「APIキーごと（ユーザーごと）」にかかるため、ユーザーが増えてもサービス全体が停止するリスクがない。
*   **透明性**: ユーザー自身がどのようなモデルを使っているか把握しやすい。

### デメリット・課題
*   **セットアップの手間**: APIキー取得というハードルがある（マニュアルでカバー可能）。
*   **プライバシー (Data Usage)**:
    *   Free Tierの規約上、入力データの一部がGoogleによるモデル改善（学習）に使用される可能性がある。
    *   **対策**: 「機密情報（パスワードや個人情報）は入力しない」旨の免責事項を規約に盛り込む。
    *   **法人対応**: データ学習を拒否したい企業ユーザーには、有料版API (Vertex AI等) のキーを使ってもらうことで解決可能（Paid Tierはデータ学習されない）。

---

## 4. 有料枠 (Pay-as-you-go) のコスト試算
仮に将来的に有料プランを提供する場合、またはヘビーユーザーが課金する場合のコスト感。

**対象モデル: Gemini 2.5 Flash**

| 項目 | 単価 (100万トークンあたり) | 日本円換算 (目安) |
| :--- | :--- | :--- |
| **入力 (Input)** | $0.10 ~ $0.15 | 約 15 ~ 22円 |
| **出力 (Output)** | $0.40 ~ $0.60 | 約 60 ~ 90円 |

**Deep Memory ブリーフィング 1回あたりのコスト試算:**
*   条件: 過去3日分のログ履歴 (約10万トークン) を入力し、レポートを受け取る。
*   計算: $0.015 (入力) = **約 2円 / 回**

**結論**:
有料化したとしても極めて低コストであり、月額サブスクリプション（例: 月額500円）でも十分な利益が出る構造である。

## 5. ロードマップへの反映
*   **Ver3.x**: BYOK設定画面の実装（現在は`.env`固定だが、設定画面から入力・保存できるようにする）。
*   **Ver4.0**: 有料/無料キーの切り替えや、法人向けVertex AI対応。
