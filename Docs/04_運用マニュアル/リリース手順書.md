# AI秘書エージェント リリース手順書

**対象**: 管理者 (リリース担当者)

---

## 1. 自動アップデートの仕組み
本アプリケーションは、GitHub Releases上のファイルを読み込んで自動更新を行います。
これを機能させるためには、**正しいファイル構成**でアップロードする必要があります。

> [!WARNING]
> **ZIPファイルだけでは自動更新されません！**
> 自動更新プログラムは `.exe` ファイルを直接探しに行きます。

---

## 2. リリース時の必須アップロードファイル
ビルド完了後、`release` フォルダ内に生成される以下の **3つのファイル** を必ずアップロードしてください。

| ファイル名 | 役割 | 必須 |
| :--- | :--- | :--- |
| **`AI Secretary Setup X.X.X.exe`** | インストーラー本体 (実体) | **YES** |
| **`latest.yml`** | 最新バージョン情報とハッシュ値 | **YES** |
| `AI Secretary Setup X.X.X.exe.blockmap` | 差分更新用のデータ (高速化用) | 推奨 |

### 補足
*   **ZIPファイル** (`AI_Secretary_Setup_X.X.X.zip`) は、手動でインストールしたい人向けのオプションです。自動更新には使われません。
*   `latest.yml` はビルドのたびに中身（バージョン番号とハッシュ値）が変わります。必ず**今のビルドで生成されたもの**を使ってください。

---

## 3. GitHub Releases での手順

1.  GitHubリポジトリの [Releases] ページへ移動。
2.  [Draft a new release] をクリック。
3.  **Choose a tag**: `v0.5.1` のようにバージョンタグを作成。
4.  **Release title**: `v0.5.1` など。
5.  **Description**: 更新内容を記述。
6.  **Attach binaries**:
    *   `release/AI Secretary Setup 0.5.1.exe` をドラッグ＆ドロップ
    *   `release/latest.yml` をドラッグ＆ドロップ
    *   (Option) `release/AI_Secretary_Setup_0.5.1.zip` をドラッグ＆ドロップ
7.  [Publish release] をクリック。

これで、既存のユーザーのアプリが `latest.yml` を検知し、自動的に `.exe` をダウンロードして更新されます。
