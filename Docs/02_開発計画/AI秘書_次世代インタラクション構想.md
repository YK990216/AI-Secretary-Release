# 次世代自律型AIエージェントにおけるインタラクション戦略
## 「秘書らしく、かつユーザーの集中を妨げない」インテリジェント・ブリーフィングの構築

本ドキュメントでは、AI秘書機能（ブリーフィング・通知）を単なる情報提示機能から、「経営判断を支援する真のパートナー」へと進化させるための具体的な機能要件と実装ロジックを定義する。
ユーザーの「集中（フロー状態）」を聖域として扱い、最適なタイミングと最高品質の深度で情報を「進言」するシステムを構築する。

---

## 1. 集中度・状況を考慮した「インテリジェント・割り込み管理」

秘書の真髄は、上司の状況を読み、「今、話しかけても良いか」を判断する能力にある。以下のロジックを実装することで、AIエージェントにその「空気感」を持たせる。

### 1.1. フォーカスレベルの自動検知

PCの操作ログからユーザーの「集中度（Focus Level）」をリアルタイムでスコアリングし、通知の可否を決定する。

*   **集中度算出アルゴリズム**:
    *   **入力密度**: 直近5分間のキーボード打鍵数（KPM: Keystrokes Per Minute）とマウス移動距離を計測。
    *   **アプリ文脈**: コーディングツール (VS Code, Cursor)、スライド作成 (PowerPoint)、ドキュメント作成 (Word, Notion) が「最前面」にある場合はベーススコアを加算。
    *   **閾値判定**: 打鍵数が一定以上（例：平均の120%以上）かつ特定の集中系アプリを使用している場合、「集中モード (Deep Work)」と判定する。
*   **実装案**: Pythonの `pynput` ライブラリ等を使用して入力をフックし、5分ごとの移動平均で集中度スコア $S_f$ を算出する。

### 1.2. カレンダー・ステータス連携

*   **会議中の抑制**: Google / M365カレンダーの予定を参照し、現在時刻に会議が入っている場合は、緊急時を除き全てのポップアップをシャットアウトする。
*   **Web会議アプリの起動検知**: カレンダーに予定がなくても、Zoom, Teams, Google Meet などのプロセスがアクティブなプロセスリストにある場合は「会議中」とみなし、割り込みを停止する。

### 1.3. 休憩リマインドの最適化（1時間ルール）

*   **適応型リマインド**: 連続作業時間が1時間に達しても、機械的にアラートを出すことはしない。
*   **タイミングの捕捉**: 上記の集中度スコア $S_f$ が低下した瞬間（作業の手が止まった、ブラウザでニュースを見始めた、SNSを開いた等）を狙って、「そろそろ、コーヒーをいかがですか？」と提案を行う。

## 2. プロンプトの洗練：エグゼクティブ秘書 (Executive Secretary) Personaの実装

提案内容を「単なるデータの要約」から「経営判断を助ける秘書の進言」へと昇華させるためのプロンプト設計。

### 2.1. Persona定義の強化

Antigravityのエージェント（`.agent/skills/`）に以下の System Instruction を組み込む。

> **Role**: あなたはFortune 500企業のCEOを20年支えてきた超一流のベテラン秘書です。
> **Tone**: 簡潔、冷静、かつ自信に満ちた口調。
> **Rules**:
> 1. 「かもしれない」「～と思います」といった曖昧な表現（Hedge words）を禁止し、「～を推奨します」「～のリスクがあります」と断言する。
> 2. 事実（Fact）と示唆（Insight）を明確に分ける。
> 3. ユーザーの「時間」を最も貴重な資産として扱い、すべての報告を1分以内に読める内容に凝縮する。

### 2.2. アイゼンハワー・マトリクスに基づく優先順位付け

AIブリーフィングの内容を、以下の4象限に整理して提示させる。

1.  **至急 (Do)**: 今日中に決裁が必要なメール、直近の会議の変更通知。
2.  **戦略的準備 (Schedule)**: 来週の重要商談に向けた事前リサーチの開始提案。
3.  **効率化 (Delegate/Automate)**: AIが代行可能な事務作業（出張の予約候補提示、経費精算の確認）。
4.  **参考 (Eliminate/Archive)**: 業界ニュースの要約など、空き時間に目を通すべき情報。

## 3. 具体的な機能アップグレード案

Antigravityのエージェントに対して実装すべき具体的な機能と、その期待される挙動。

| 機能名 | 実装指示イメージ (Prompt) | 期待される挙動 |
| :--- | :--- | :--- |
| **スマート通知制御** | 「`pynput`を使用してマウスとキーボードの活動密度を監視し、集中度スコアが0.8以上の時はブリーフィングのポップアップを15分延期するロジックを実装して」 | ユーザーが没頭している間の邪魔を防ぎ、集中が切れたタイミングでのみ情報を提示する。 |
| **事前ブリーフィング強化** | 「カレンダーの次の予定の参加者をLinkedIn APIや社内DBで調べ、過去のメール履歴と統合した『1枚の事前ブリーフィング』を生成するSkillを作って」 | 会議の直前に、相手の経歴、前回の決定事項、懸念点を瞬時に把握可能にする。 |
| **アクティブ休憩提案** | 「1時間連続でアプリがアクティブな場合、カレンダーの空き時間を確認した上で『次の予定まで15分あるので、一度画面から離れることをお勧めします』と通知して」 | ユーザーの体調とスケジュールの両面から、実行可能な最適な休憩を促す。 |

## 4. 戦略的アドバイス：ブランドの確立

経営層向けのサービスとして成功させるための核心は、**「沈黙の質」**にある。
「何でも通知してくるAI」はノイズとして嫌われる。**「今話しかけるのが最善であると判断した時だけ現れるAI」**というブランディングを確立することが、多忙なエグゼクティブ・ユーザーの信頼を勝ち取る唯一の道である。
