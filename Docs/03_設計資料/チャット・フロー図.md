# チャット・アーキテクチャ データフロー図

**作成日**: 2026/02/04
**概要**: ElectronクライアントからVertex AIまでの通信フロー。

```mermaid
sequenceDiagram
    participant User as ユーザー (アプリ)
    participant Func as Cloud Functions (中継)
    participant Auth as 認証システム
    participant DB as Firestore (記憶)
    participant Brain as Vertex AI (脳)

    User->>Func: 1. メッセージ送信
    activate Func
    
    Note right of Func: セキュリティ確認
    Func->>Auth: 2. トークン検証
    Auth-->>Func: OK
    
    Note right of Func: 文脈読み込み
    Func->>DB: 3. ログ取得
    DB-->>Func: ログデータ

    Func->>Brain: 4. プロンプト送信
    activate Brain
    Brain-->>Func: 5. 回答生成
    deactivate Brain

    Func-->>User: 6. 回答返信
    deactivate Func
```

## 解説
1.  **認証**: Cloud Functions でトークンを検証します。
2.  **文脈読込**: FunctionsがFirestoreから必要な記憶（ログ）を読み込みます。
3.  **思考**: ユーザーのメッセージとログを合わせてVertex AIに送信します。
4.  **回答**: 生成されたテキストがアプリに返されます。
