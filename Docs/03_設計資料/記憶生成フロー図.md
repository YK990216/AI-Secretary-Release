# 記憶生成 (Create Memory) フロー図

## 概要
ユーザーの1日の活動ログを分析し、構造化された「記憶 (Memory)」を生成するプロセス。
Ver 0.5.1 以降、**BFF (Backend for Frontend)** パターンを採用し、ログの取得と加工をサーバー側 (Cloud Functions) に集約しています。

## シーケンス図

```mermaid
sequenceDiagram
    autonumber
    actor User as ユーザー
    participant Client as Windows App<br>(MemoryService)
    participant Func as Cloud Functions<br>(generateDailySummary)
    participant DB as Firestore<br>(activity_logs)
    participant AI as Vertex AI<br>(Gemini 1.5 Flash)
    participant DB_Mem as Firestore<br>(memories)

    User->>Client: "Create Memory" ボタン押下
    
    Note over Client: 1. リクエスト準備
    Client->>Client: 対象日付の開始・終了時刻を計算<br>(Local Time 0:00 - 23:59)
    
    Client->>Func: call(dateStr, startTime, endTime)
    activate Func
    
    Note over Func: 2. ログ収集 (BFF)
    Func->>Func: Auth Token検証
    Func->>DB: Query: Log between startTime & endTime
    DB-->>Func: Log Documents
    
    alt ログなし
        Func-->>Client: Return Empty Memory
    else ログあり
        Func->>Func: ログをテキスト化 & プロンプト構築
        
        Note over Func: 3. AI生成
        Func->>AI: generateContent(Logs + Schema Prompt)
        AI-->>Func: JSON Response
        
        Func->>Func: JSON Parse & Validate
        Func-->>Client: Return Memory Object
    end
    deactivate Func
    
    Note over Client: 4. 確認と保存
    Client->>User: 生成結果を表示 (プレビュー)
    
    opt ユーザーが保存を実行 (自動/手動)
        Client->>DB_Mem: saveMemory(date, memoryData)
        Client->>User: "Memory Saved" 通知
    end
```

## データ構造

### Request (Client -> Cloud Functions)
```json
{
  "dateStr": "2026-02-06",
  "startTime": "2026-02-05T15:00:00.000Z", // UTC (JST 0:00)
  "endTime": "2026-02-06T14:59:59.999Z"   // UTC (JST 23:59)
}
```

{
