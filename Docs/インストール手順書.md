# AI秘書エージェント インストール・アンインストール手順書

**対象バージョン**: v0.5.0 以降
**OS**: Windows 10 / 11

---

## 1. インストール手順

1. 配布された `AI Secretary Setup x.x.x.exe` をダブルクリックして実行します。
2. 自動的にインストールが開始され、デスクトップにショートカットが作成されます。
3. インストール完了後、アプリケーションが自動的に起動します。

> [!NOTE]
> 初回起動時、Windows Defender SmartScreen の警告が表示される場合があります。その際は「詳細情報」→「実行」を選択してください（署名未登録のため）。

---

## 2. アンインストール手順

標準的な Windows アプリケーションと同様の手順でアンインストール可能です。

### 方法 A: 「設定」から削除する (推奨)
1. Windowsの **[スタート]** ボタンを右クリックし、**[インストールされているアプリ]** (または [アプリと機能]) を選択します。
2. リストから **"AI Secretary"** を検索します。
3. 右側のメニュー (･･･) から **[アンインストール]** をクリックします。
4. 有効化されると自動的に削除処理が行われます。

### 方法 B: インストールフォルダから削除する
本アプリは以下のフォルダにインストールされます。この中の `Uninstall AI Secretary.exe` を実行することでも削除可能です。

*   `%LOCALAPPDATA%\Protegrams\AI Secretary\`
    *   (通常は `C:\Users\ユーザー名\AppData\Local\Programs\AI Secretary\`)

---

## 3. データ削除について (完全削除)

アプリをアンインストールしても、ログイン情報や一部の設定ファイル（セキュアトークンなど）が残る場合があります。
完全に初期化したい場合は、以下のフォルダも手動で削除してください。

*   `%APPDATA%\ai-secretary-agent`
    *   (通常は `C:\Users\ユーザー名\AppData\Roaming\ai-secretary-agent\`)
