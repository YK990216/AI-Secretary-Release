# AI秘書アプリ (Windows MVP) 起動マニュアル

本アプリケーションの起動方法（ウィンドウの開き方）について説明します。

## 前提条件

- Node.js がインストールされていること
- 開発用PCであること

## 起動手順

1. **コマンドプロンプト** または **PowerShell** を開きます。
2. アプリケーションのディレクトリに移動します。
   ```powershell
   cd C:\DEV\AI秘書\windows-mvp
   ```
3. 以下のコマンドを入力して実行します。
   ```powershell
   npm run dev
   ```
4. 初回起動時など、依存ライブラリがインストールされていない場合は、先に以下を実行してください。
   ```powershell
   npm install
   ```
5. コマンド実行後、自動的にアプリケーションウィンドウが立ち上がります。

## トラブルシューティング

- **ウィンドウが開かない場合**:
  - コマンドラインにエラーが表示されていないか確認してください。
  - `active-win` や `PowerShell` のセキュリティ警告が出ていないか確認してください。

- **ポート使用中エラー**:
  - 別のプロセスがポートを使用している可能性があります。その場合、自動的に別のポートで起動しようとしますが、失敗する場合は既存の `node` プロセスを終了してください。

- **Googleログイン時の警告「このアプリはGoogleによって確認されていません」**:
  - 開発中アプリのため表示されます。以下の手順で進んでください。
  1. 「詳細」をクリック
  2. 「ai-secretary-xxxxx (安全ではないページ) に移動」をクリック
  3. 必要な権限（カレンダー等）にチェックを入れて「続行」をクリック
  - 一度許可すれば、次回以降は自動ログイン機能により表示されなくなります。
