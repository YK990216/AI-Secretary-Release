# 既知の問題 (Known Issues)

現在確認されている主な既知の問題と、その回避策について記載します。

---

## 1. カレンダー情報が更新されなくなる (v0.6.5)

### 現象
アプリケーションを起動したまま **約1時間** が経過すると、Googleカレンダーの予定が最新の状態に更新されなくなる場合があります。

### 原因
Googleのセキュリティポリシーにより、現在の認証方式では長時間のアクセス権（リフレッシュトークン）の維持に制限があるためです。
※ 本件は技術的な調査が完了しており、次期バージョン **v0.7.0** にて根本修正（認証基盤の刷新）を予定しています。

### 回避策
*   **アプリの再起動**: アプリを一度終了し、再度起動してください。自動的に再認証が行われます。
*   **ログアウト/ログイン**: 設定画面から一度ログアウトし、再ログインすることでも解消されます。

---

## 2. 過去の活動ログが「活動なし」と判定される

### 現象
AIチャットで「今日の10時の活動は？」のように過去の作業内容を尋ねた際、実際には作業をしていても「活動記録がありません」と返答されることがあります。

### 原因
現在のAIは「直近の会話履歴」と「現在のスケジュール」を中心にコンテキストを生成しており、過去の膨大なログデータを全て検索・参照する機能（長期記憶の検索）が未実装のためです。

### 今後の対応
将来的なバージョンで、過去ログの検索機能（RAG）の実装を検討しています。

---

## 3. インストール時に警告が表示される

### 現象
Windowsへのインストール時、「WindowsによってPCが保護されました (Microsoft Defender SmartScreen)」という青い画面が表示される。

### 原因
本アプリが個人の開発者によって署名されている（または署名がない）ため、Microsoftの信頼済みリストに登録されていないことが原因です。ウイルス等の問題ではありません。

### 回避策
「詳細情報」をクリックし、「実行」ボタンを押すことでインストールを進めることができます。
