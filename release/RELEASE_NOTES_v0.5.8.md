# AI Secretary v0.5.8

## 🎯 新機能

### 🚀 PC起動時の自動起動
- アプリケーションがPC起動時に自動的に立ち上がるように設定されます
- バックグラウンドで常駐し、作業開始時からすぐに活動ログの記録とアシスト機能が利用可能になります

### 🔄 カレンダー認証の永続化
- **Google Calendar**: アクセストークンを45分ごとに自動更新する機能を追加
- **Outlook Calendar**: データ取得時にMSALのサイレント認証（`acquireTokenSilent`）を使用し、自動的にトークンを更新
- これにより、長時間アプリを起動し続けても、ログイン・ログアウトを繰り返すことなくカレンダー情報が継続的に取得できるようになりました

## 🐛 修正内容
- バックグラウンド実行後にカレンダー情報が取得できなくなる問題を解決
- トークン有効期限切れによる認証エラーを防止

---

**インストール方法**: `AI-Secretary-Setup-0.5.8.exe` をダウンロードして実行してください。

**自動更新**: v0.5.7以降をご利用の方は、次回起動時に自動的に更新が適用されます。
