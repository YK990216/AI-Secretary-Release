# Release Notes v0.6.2

## 概要
認証・ログイン体験の大幅改善とMermaidダイアグラムの拡張対応を実施しました。

## ✨ 新機能

### スマートログイン (Smart Login)
- **リフレッシュトークン活用**: 初回ログイン時に取得したリフレッシュトークンをPC内に安全に保存し、2回目以降のログインで「権限許可画面」をスキップできるようになりました。
- **シームレスな再ログイン**: アプリ起動時にトークンを自動チェックし、有効な場合はアカウント選択のみでログイン完了。

### 認証セキュリティの強化
- **Client Secret対応**: Googleカレンダー連携のトークンリフレッシュにClient Secretを追加し、Webアプリケーション認証の標準仕様に準拠しました。
- **詳細なエラーログ**: トークン更新失敗時の原因を特定しやすくなりました。

### Mermaid対応ダイアグラムの拡充
- これまで一部の基本ダイアグラム（フローチャート、シーケンス図など）のみに制限されていましたが、制限を解除し、Mermaidがサポートするほぼ全ての記法に対応しました。
- **新たに対応した主な図**:
    - マインドマップ (`mindmap`)
    - タイムライン (`timeline`)
    - Gitグラフ (`gitGraph`)
    - ユーザージャーニー (`journey`)
    - サンキー図 (`sankey`)
    - その他（Requirement Diagram, C4, Block Diagramなど）

## 🐛 バグ修正

### 誤ったログアウト処理の修正
- **問題**: Googleアカウントでログインしている場合でも、ログアウト時にMicrosoftアカウントのサインアウト画面が表示されていました。
- **修正**: Microsoftアカウントトークンが存在する場合のみMSALログアウト処理を実行するように変更しました。

### カレンダー連携のエラーハンドリング改善
- 認証切れ（401エラー）時に「再ログインが必要」と明確に表示されるようになりました。

## 🛠 変更点
- **内部ロジックの修正**: `MermaidRenderer` における表示許可リストの正規表現を更新しました。
- **トークン管理の最適化**: `firebase.ts` と `App.tsx` のトークンリフレッシュロジックを改善しました。

## 📋 今後の予定
次のバージョン（v0.7.0）では、以下の機能を予定しています：
- **フェーズ1: 信頼の境界線 (Trust Boundaries)** - AI作業用フォルダの明示的指定とアクセス制御
- **コンテキスト認識型認証** - 環境指紋による異常検知とWindows Hello連携
