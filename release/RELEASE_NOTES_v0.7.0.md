# AI Secretary v0.7.0 Release Notes

**リリース日**: 2026/02/19

## ✨ ハイライト: 認証基盤の刷新と安定化

本バージョンでは、Googleカレンダー連携の安定性を飛躍的に向上させるため、認証システムをゼロから再構築しました。
これまでの「1時間ごとに更新が止まる」問題が解消され、一度ログインすれば長期間バックグラウンドで安定して動作します。

## 🚀 主な変更点

### 1. 🔑 ネイティブOAuth 2.0認証の実装
*   **変更前**: アプリ内のポップアップウィンドウで簡易的にログインしていました。
*   **変更後**: **お使いの標準ブラウザ（ChromeやEdgeなど）が立ち上がり、安全にログインできるようになりました。**
*   これにより、Googleの最新のセキュリティ基準に準拠し、より信頼性の高い接続が可能になりました。

### 2. 🛡️ セキュリティ強化 (safeStorage)
*   認証情報（リフレッシュトークン）の保存先を、ブラウザのLocal Storageから **Windows OS標準の暗号化領域 (DPAPI / safeStorage)** に変更しました。
*   他のアプリやマルウェアによる読み取りリスクを大幅に低減しつつ、アプリ再起動後もスムーズに自動ログインします。

### 3. 🐛 バグ修正
*   **カレンダー自動更新の停止**: 1時間経過後にバックグラウンド更新がエラーになる問題を完全に修正しました。
*   **誤ったエラー通知の抑制**: 一時的なネットワークエラーなどで不要な通知が出ないよう調整しました。

## ⚠️ 注意事項

*   **再ログインが必要です**: v0.7.0へのアップデート後、初回起動時に**ブラウザでの再ログイン**が求められます。画面の指示に従ってログインしてください。
*   旧バージョン(v0.6.x)での設定は引き継がれますが、認証情報のみリセットされます。
